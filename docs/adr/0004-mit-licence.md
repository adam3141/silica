# 0004. MIT licence for every repository

- Status: Accepted
- Date: 2026-11-24

## Decision

silica, flint, agate and opal are released under the MIT licence. Each repository has its own `LICENSE` file.

## Consequences

Third-party dependencies must have MIT-compatible licences. The current ones are: GoogleTest (BSD-3), Tracy (BSD-3) and SDL3 (zlib).
